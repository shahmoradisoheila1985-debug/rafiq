# رفیق — نسخه اولیه وب‌اپلیکیشن

یک نمونه وب‌اپ فارسی، راست‌چین و واکنش‌گرا برای موبایل و کامپیوتر. فایل اصلی `index.html` است و به نصب کتابخانه یا سرور برای پیش‌نمایش نیاز ندارد.

## اجرای فوری
1. فایل ZIP را استخراج کنید.
2. روی `index.html` دوبار کلیک کنید تا در مرورگر باز شود.
3. فیلترهای دورهمی و فرم را آزمایش کنید.

## محدودیت مهم فرم
فرم فعلی صرفاً نمایشی است. پاسخ‌ها در حافظه محلی همان مرورگر ذخیره می‌شوند و به سازنده سایت نمی‌رسند. تا زمانی که فرم به یک سرویس آنلاین وصل نشده، از این نسخه برای جمع‌آوری اطلاعات واقعی استفاده نکنید.

## انتشار رایگان (یکی از راه‌ها: GitHub Pages)
1. در GitHub وارد حساب خود شوید و یک repository عمومی با نامی مثل `rafiq` بسازید.
2. فایل `index.html` را در ریشه مخزن بارگذاری کنید.
3. به Settings → Pages بروید، در بخش Build and deployment گزینه Deploy from a branch را انتخاب کنید، branch اصلی و پوشه `/ (root)` را انتخاب و Save کنید.
4. آدرس منتشرشده را از همان بخش باز کنید.

## پیش از استفاده واقعی
- یک فرم آنلاین مثل Google Forms یا سرویس رایگان مشابه بسازید و آن را به صفحه وصل کنید.
- سیاست حریم خصوصی کوتاهی اضافه کنید و فقط اطلاعات ضروری را بگیرید.
- زمان، مکان، ظرفیت و هزینه هر دورهمی را پیش از اعلام، قطعی کنید.
- برای مدیریت ثبت‌نام‌ها و لغوها، یک روش پاسخ‌گویی مشخص کنید.

این نمونه شامل ورود کاربران، پنل مدیریت، پیامک، پرداخت، یا ثبت‌نام آنلاین واقعی نیست.
